# agents/: the team's working files

| File | What it is for | Who updates it |
|---|---|---|
| `STATUS.md` | What is merged, what is open, what is blocked, what needs a decision | Anyone who finishes a task |
| `PRODUCT.md` | Founder decisions and product rules | CTO, when the founder decides something |
| `BACKEND.md` | Firebase, the Circles Worker, rules, secrets, deploy steps | Whoever changes the backend |
| `DEV_BUILDS.md` | How to build and publish a dev APK | Whoever changes the build |
| `PLAY_STORE.md` | How to build and upload the Play bundle | Whoever changes the release |
| `TESTING.md` | Test commands, known gotchas, device checks | Anyone who finds a new gotcha |

Keep each file short. Replace out-of-date facts rather than adding a second version of them.
