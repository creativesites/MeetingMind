Work: remember the work, see what changed, know what to do next.

An interactive redesign of the Work vertical on release/1.0-paid-launch, built on the current code, the approved decisions D1–D7 and Direction v2. Every phone below is live: tap rows, chips, sources (▶ 18:40), sheets and buttons. One scenario runs through all of them: Ana Mwansa, an independent consultant, on Tuesday 17 November 2026. Her client is Acme Corporation (project Acme Integration, with Sarah Chen and James Obi). There is also a new prospect, Kalahari Logistics, and a confidential board role at Zenith Capital.

The full rationale, the audit and the implementation mapping are in design/work-vertical-design-spec.md. The tags on each frame say how real it is: built exists today and is restyled · improve exists, and the behaviour or layout changes · new UI uses data the app already has in a new surface · later is shown as unavailable, not as live.

1 · Work Pulse: the daily habit

One screen, ordered by time of day: Next (prep before meetings, review after them), Needs you (at most four, each with one verb), Today as a timeline, Since yesterday as plain sentences, and Ask. Empty sections don't appear, so a quiet day stays quiet. Try the Pulse moment switch above.

2 · Intelligence Brief: the wow

A document you can send. Records supply the sections; AI writes two short paragraphs and every sentence cites its source. Pick the type (project, client, meeting, relationship, weekly), then export or share. Without a model it still renders, minus the prose. Nothing is sent automatically.

3 · Memory: long-term value

Ask is scoped to where you are (project, person, organisation). Questions like "What am I waiting for?" are answered from your records instantly and offline. Open questions get cited prose. With no source there is no answer: the screen says what's missing instead.

How they reinforce each other

Pulse shows what changed → its source chip shows why → the context page and Ask give the history → a Brief turns it into something to send → the next meeting's Wrap-up updates memory → tomorrow's Pulse picks it up.

Why this is easier than today

  • One Work home. The dark Pulse card and the 15-block Professional home go. The Today home gets one short Work card (D1, D7).
  • Inbox appears once, in the header with a badge, and in Pulse only when it needs you. Today it appears in 4–5 places.
  • No second notes list. Notes keeps the library; Work search and project pages find work notes (F-2).
  • WorkAll is absorbed. Its six tabs were a copy of Tasks plus Decisions; they now live in two segments.
  • One project page instead of ProjectScreen and ContextScreen side by side.
  • Header search covers Work (D2); Ask is in Pulse, ⋯ and every context page (D3).

Decisions for the founder

F-1 · Work in the fourth bar slot for work profiles?

D6 keeps Search as the default slot; Direction v2 §D9 gives Work the slot for work identities. Recommendation: keep D6 for everyone else, and put Work in the slot by default when someone picks a work profile in onboarding. Search stays one tap away from every header.

F-2 · Retire the Work "Notes" segment?

WORK_UX (9 Oct) made notes the founder's priority on the Work page. Direction v2 §D9 says "Notes stays as it is" and Work holds the records. Recommendation: retire the segment, and keep work notes one tap away through the Notes tab's remembered Work filter, project pages and Work search. Alternative: keep it as a fifth segment that is the same Notes component, scoped to Work.

F-3 · Autopilot: tasks go to review by default?

Today, auto-run creates tasks directly when it is on, which skips the confirmation the Wrap-up enforces everywhere else. Recommendation: by default, put them in the Wrap-up as unreviewed findings, with "Create directly" as an opt-in.

F-4 · Brief controls

The engine has five brief kinds; the screen exposes none of them, and there are no tone, length or copy controls. Recommendation: ship the kind picker and Copy in the first increment, then audience, tone and length in the second. They only change the two AI paragraphs, never the sections.

F-5 · Reading PDF and web text

The Inbox can't read text inside PDFs, scans or links today, so it files those by name only. The design labels this honestly. Question: should on-device PDF text extraction be added to the Inbox roadmap? It is not in this redesign's scope.

F-6 · Retire the Work home style?

D1 approved a short entry. Recommendation: keep HomeStyle.PROFESSIONAL as a choice. It becomes the Today home with the Work card pinned first and the Work slot on, so nobody loses their setting.
