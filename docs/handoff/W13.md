## Built

1. **Providers with capabilities (`core/integrations/`):**
   - `Capability`: lists what each connection enables (`CALENDAR_EVENTS`, `CALENDAR_ATTENDEES`, `CALENDAR_PREP`, `CALENDAR_WORKFLOW_RULES`, `EMAIL_INDEX_READ`, `EMAIL_DRAFT_SEND`, `EMAIL_ATTACH_MINUTES`, `STORAGE_IMPORT_DOCS`, `STORAGE_ATTACHMENTS`, `STORAGE_RETRIEVAL`, `OUTPUT_SHARE_SHEET`, `OUTPUT_DIRECT_MESSAGE`, `MEETING_RECORDING_IMPORT`, `TASK_MIRROR_OUT`).
   - `IntegrationProvider`: base interface with id, name, category, capabilities, status, isEnabled, accountScope, and privacyNotice.
   - `CalendarProvider`, `EmailProvider`, `StorageProvider`, `OutputChannel`, and `MeetingProvider` domain interfaces.
   - `DeviceCalendarProvider`: adapts existing `CalendarEvents` behind `CalendarProvider` with zero behavioral changes.
   - `ShareSheetOutputChannel`: adapts `ShareHelper` and the system Sharesheet behind `OutputChannel`.
   - `SafStorageProvider`: adapts Android Storage Access Framework (SAF) document picker behind `StorageProvider`.
   - `IntegrationRegistry`: centralized registry of all providers and capability querying.
   - `IntegrationPreferences`: DataStore persistence for active provider toggles, local "Notify me" taps, and confidential opt-in flags.

2. **The Integration Centre (`feature/settings/`):**
   - Accessible via Settings → **Integrations** (`Routes.INTEGRATIONS`).
   - **Active on device:** Phone Calendar, Share to Apps, Device Storage (SAF), each detailing its enabled capabilities and data scope.
   - **Email Correspondence:** Gmail and Outlook cards (shown when feature flag is enabled), detailing capabilities and the strict scope ("Messages with known contacts and domains only").
   - **Confidentiality guard:** Clinical and Legal profiles display an explicit confidentiality notice and switch to protect sensitive client/patient correspondence.
   - **Planned integrations (Founder interest signals):** Google Drive, Microsoft OneDrive, Dropbox, Slack, Zoom, Google Meet, Microsoft Teams, HubSpot. Each row features a local "Notify me" button stored in DataStore.

     - Debug: Dev client ID (`785434731634-p56sa9uf14ivlnfh2hubtn1j6nrhta7u.apps.googleusercontent.com`) and dev redirect URI (`msauth://com.craftflowtechnologies.meetingmind.dev/...`).

## How to see it

1. Open **Settings** → **Integrations**.
2. See the active connections: Phone Calendar, Share to Apps, Device Storage (Files), with their enabled capabilities.
3. Scroll to "Planned Integrations" (Drive, OneDrive, Dropbox, Slack, Zoom, Meet, Teams, HubSpot) and tap "Notify me" on any item to toggle interest notification.

## Risks / questions for the orchestrator

- **Email restricted scopes:** When `FEATURE_INTEGRATIONS_EMAIL` is turned on in production, Google verification for `gmail.readonly` requires completing Google's app verification and security assessment. The dev client ID is restricted to test accounts in the developer console.
- **Microsoft Entra config:** As noted in `docs/INTEGRATION_CREDENTIALS.md`, the owner must ensure the Entra portal has the multi-tenant `common` authority configured and the two Android redirect URIs registered.
