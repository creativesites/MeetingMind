# MeetingMind dev build

**MeetingMind-Dev-3d71d16.apk**: "MeetingMind Dev" built from commit `3d71d16` on `claude/meetingmind-mvp-planning-7dgowm`
(arm64-v8a, 72 MB). It installs beside the tester app (`com.craftflowtechnologies.meetingmind.dev`) and keeps its own data.

New in this build:
- **Note blocks:** insert the summary or the transcript into a note as formatted blocks.
- **Sermons** add their transcript to the note automatically.
- **Recording screen redesign** with buttons that fit the recording type; for sermons, highlight key moments and add notes live.
- **Work notes** are back in Notes.
- **Everyday home**, the new default for fresh installs; the Today page is unchanged. Switch in Settings → Look and home.
- **Circles:** push notifications, share a Create card into chat, anonymous-author fix, Google account linking (needs setup).

Install: allow installs from unknown sources, then open the APK. Only the latest build is kept on this branch.
