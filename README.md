# MeetingMind dev build

**MeetingMind-Dev-240f8db.apk**: "MeetingMind Dev" built from commit `240f8db` on `claude/meetingmind-mvp-planning-7dgowm`
(arm64-v8a, 73 MB). It installs beside the tester app (`com.craftflowtechnologies.meetingmind.dev`) and keeps its own data.

New in this build:
- **One Bible place**: Continue where you left off, Today's reading with Guide me / Just read, How I feel, Study a passage,
  plans, and an auto-saving study journal. Guided sessions (SOAP, verse by verse) where Zuri asks and you answer.
- **Reader**: "Guide me" on selected verses; "Explain" for commentary, cross-references and Hebrew/Greek.
- **Faith home rebuilt**: Bible, Today's devotional, Pray with me and Circles up top; quiet "Write a …" tiles below.
- **Devotional**: Write your reflection (saves itself to the journal), Live it today, archive reads as a journal.
- **Settings**: 8 groups, search, Advanced tucked away, one Notifications screen.
- **Notes library**: search first, filter chips (incl. Bible), richer rows, ranked search, bulk actions with undo.

Install: allow installs from unknown sources, then open the APK. Only the latest build is kept on this branch.
